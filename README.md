# Data Structures Visualizer 🧠

A C++ console application to interactively visualize and manipulate core data structures.

Built by **Yousuf Magdy** — Computer Engineering Student, Badr University Cairo.

---

## 📦 Data Structures Included

| Structure | Operations |
|---|---|
| Linked List | Insert, Delete, Search, Display |
| Stack | Push, Pop, Peek, Display |
| Queue | Enqueue, Dequeue, Peek Front, Display |
| Binary Search Tree | Insert, Search, Inorder Display |

---

## ▶️ How to Compile & Run

Make sure you have `g++` installed.

**On Mac / Linux:**
```bash
g++ main.cpp -o visualizer
./visualizer
```

**On Windows:**
```bash
g++ main.cpp -o visualizer.exe
visualizer.exe
```
